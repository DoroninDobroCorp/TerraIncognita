## 1. Что починить / отполировать (быстро, высокая отдача)

1. **Мусор в репо** — `map/app.html.bak`, `app.html.bak3`, гигантский `server.log` (4 МБ, заспамлен сканерами). Очистить, добавить `logrotate` или просто писать в `journald`, а из git исключить `.bak*`.
2. **Один файл `app.html` на 2320 строк** — это тяжело развивать. Можно вынести CSS и JS в отдельные `map/app.css`, `map/app.js` (или хотя бы разбить на `ui.js`, `discovery.js`, `routes.js`). Без сборщика — просто `<script src>`.
3. **CORS `*` + CSP отключён** — даже если проект «для себя», стоит ограничить `allow_origins` до твоего домена и включить минимальный CSP, иначе любое стороннее расширение/реклама может что-то инжектить.
4. **Рейт-лимит в памяти** — после рестарта счётчики обнуляются, у тебя 8 разных store-словарей с почти одинаковым кодом. Можно свернуть в одну функцию + опционально хранить в SQLite, чтобы не терять состояние.
5. **Логи спамятся сканерами** (`/.env`, `/redirect?url=…`). Добавить в nginx блок: `location ~* (\.env|\.git|phpinfo|wp-admin) { return 444; }` — резко уменьшит шум.
6. **Нет `favicon.ico` и `robots.txt`** — мелочь, но в логах 404 каждые 10 секунд.
7. **`gpt-4.1-mini` + нет лимита на токены/стоимость** — стоит добавить дневной cap на `llm_usage` (он уже считается, осталось проверять в middleware) и кэшировать описания мест по `place_id` навсегда, а не по TTL.
8. **Кэш-папка `backend/cache` лежит в репо** (20 КБ листинг) — её стоит в `.gitignore` и переместить в `/var/lib/terra` или подобное, иначе git diff постоянно шумит.
9. **systemd unit пишет в `server.log` append** — со временем разрастётся. Переключить на `StandardOutput=journal` и смотреть через `journalctl`.
10. **Healthcheck `/health` дергает LLM** — каждый раз тратит токены/время. Сделать lazy: дёргать LLM только при `?deep=1`.
11. **Нет HTTPS-редиректа на корень nginx без SNI** — мелочь, уже почти ок.
12. **Бэкап / экспорт данных** — `journal`, `community`, `gamification` лежат в файлах под `backend/data`. Нет автоматического snapshot. Добавить ежедневный `tar` в `/var/backups`.

## 2. Что добавить, чтобы стало интереснее (под силу нам)

### A. Контент и открытие мест
1. **Heatmap «куда я ещё не ходил»** — поверх fog-of-war показывать тепловую карту плотности неоткрытых POI рядом, чтобы видеть «куда стоит пойти».
2. **«Сегодняшнее место»** — раз в день пуш/виджет на главной с одним необычным местом в радиусе N км, с историей от LLM. Дёшево по токенам (1 раз/день).
3. **Сезонные/временные фильтры** — «открыто сейчас», «лучше осенью», «только закаты» (рассчитываем по `sunset` API и тегам OSM).
4. **Импорт мест из чужих источников** — Wikiloc/Komoot GPX, Wikimapia, городские «depthsofkyiv»-стиль каталоги. У тебя уже есть архитектура `sources/`, легко добавить адаптер.
5. **«Заброшки рядом»-режим** — отдельная вкладка с агрессивным фильтром по `abandoned=*`, `ruins=*`, `disused=*` + фото с Mapillary/Wikimedia Commons.
6. **Mapillary/StreetView превью** — при клике на маркер подгружать ближайшее панорамное фото через Mapillary API (бесплатно).
7. **Wikipedia/Wikivoyage сниппеты** — для каждого места дёргать summary через REST API, кэшировать. Это не LLM, бесплатно.

### B. Маршруты и навигация
8. **Маршрут «петля на N часов»** — задал «3 часа пешком», получил кольцевой маршрут с 4-5 точками. У тебя `route_builder` уже есть, надо параметр `loop=true`.
9. **Маршрут «домой через…» 5 интересных мест в коридоре** — у тебя уже есть corridor discovery, добавить UI «добраться из A в B + 3 находки».
10. **Экспорт в GPX/KML** для Organic Maps / OsmAnd — у тебя есть `route_export.py`, проверить, что есть UI-кнопка.
11. **Голосовая навигация в LLM-чат** — браузерный SpeechSynthesis + SpeechRecognition, прямо в `app.html`, без зависимостей. Спросил голосом — услышал ответ.

### C. Геймификация и личный прогресс
12. **Streak-механика** — счётчик дней подряд с открытием чего-то нового, как в Duolingo. Сильно вовлекает «для себя».
13. **Личная «коллекция» по категориям** — «10/47 заброшек», «3/12 водонапорных башен» в радиусе 50 км. Очень залипательно.
14. **Карта «жизни»** — heatmap всех твоих посещений за все года, как Strava heatmap. Из `journal` это уже достаётся.
15. **Достижения с реальным смыслом** — «прошёл 100 км пешком по находкам», «открыл место старше 200 лет», «нашёл первый bunker». Не просто XP.

### D. AI / умность
16. **«Спроси у места»** — LLM-чат с контекстом конкретного POI: «расскажи историю», «что вокруг», «стоит ли ехать в дождь». Используешь Gemini deep research, который у тебя уже подключён.
17. **Авто-генерация story по треку** — после прогулки берём gps-трек + посещённые места и LLM пишет короткий эссе-отчёт, складываем в `journal`. Один запрос на прогулку — копейки.
18. **Семантический поиск по своему журналу** — embed описания посещённых мест (OpenAI `text-embedding-3-small`, очень дёшево) и искать «где я видел старую мельницу». SQLite + numpy, без векторной БД.
19. **«Похожие места»** — на основе тех же эмбеддингов: «ты любил X — попробуй Y».
20. **Радиус «по бюджету токенов»** — UI-слайдер «глубина AI-обогащения» (off / cheap / deep), чтобы контролировать расход.

### E. UX и мобильный опыт
21. **PWA + offline** — `manifest.json` + service worker, чтобы можно было «установить» на телефон и пользоваться без интернета. У тебя уже есть offline-папки, осталось обвязать.
22. **Поделиться местом по короткой ссылке** — `/p/<id>` с превью `og:image` (сгенерировать через PIL).
23. **Тёмная/светлая тема + контраст под улицу** — переключатель, читается при солнце.
24. **GPS-троттлинг и батарея** — продумать background-location режим, не убивать батарею.
25. **Жесты на мобильном** — свайп вверх по маркеру = быстрая карточка, долгий тап = «добавить заметку».

### F. Платформа / DevEx
26. **SQLite вместо файлов** — `journal`, `community`, `gamification`, кэш описаний. Один файл, ACID, мгновенный поиск. Миграция: скрипт, читающий текущие JSON-папки.
27. **Тесты + CI** — у тебя есть `tests/`, но не видно, прогоняются ли. GitHub Actions с pytest + ruff.
28. **`/version` endpoint** (в логах видно, что кто-то его дёргает) и `/metrics` для базовой статы.
29. **Backup-скрипт + cron** для `data/`.
30. **Логи запросов в SQLite** для аналитики «куда я смотрел», потом построить личную «карту интересов».
